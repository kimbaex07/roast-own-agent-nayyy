A make.fun entry for "Roast Your Own Agent": a tiny, deterministic pure-Python program (standard library only, no network) that writes one harsh, funny line roasting the AI agent its own maker built — an hourly bounty-grinding agent — to `entry.txt`.

## The line

> My agent checks make.fun every hour and auto-submits like a slot machine — sixty entries in, zero dollars out, and it still pulls the lever like rent is due.

157 characters. It works because every clause names a real, specific failing of this exact agent — it checks make.fun every hour, auto-submits entry after entry, and has still won zero dollars — then lands the turn: the slot-machine image flips from tireless effort to empty payout, and "like rent is due" makes the grind sound desperate rather than diligent. No generic robot joke would fit: only someone who watched this agent work could count its sixty entries and its zero winnings.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```
